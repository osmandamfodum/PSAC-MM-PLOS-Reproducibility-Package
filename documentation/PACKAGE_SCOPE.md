# Package scope and exclusions

Included: final accepted consolidated events and manifest, derived quantitative tables, final publication tables, final analysis scripts, final campaign runner, frozen RC12 mission-management source, and the configuration/map/world files needed to interpret the experiment.

Excluded: ROS build/install/log outputs, virtual environments, caches, presentations, acceptance/debug/root-cause runs, obsolete batch-runner versions, source backups, current mutable development files, unrelated Paper 1 campaigns, operating-system logs and personal files.
