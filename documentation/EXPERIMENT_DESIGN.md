# Experiment design

The final campaign uses scenarios S1, S2 and S3; methods B1, B2, B3 and P; and seeds 1001–1010. The schedule was randomized by the retained final runner using schedule seed 20260920. One mission run is the independent experimental unit. Each scenario-method cell contains 10 accepted runs and each run contains three target opportunities. Navigation failures remain valid quantitative observations. Infrastructure-invalid attempts are retained outside this package and are excluded by the final manifest.
